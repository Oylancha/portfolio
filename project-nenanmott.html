Language Learning App

Project Overview

A Chechen language learning application designed to help users learn and practice the Chechen language through interactive lessons and exercises.

System Architecture & Data Flow

The platform utilizes a robust, decoupled architecture separating local data processing and state management from external cloud and AI microservices. The Flutter client heavily relies on a local SQLite database for instantaneous data retrieval and offline capability.

  • Local Processing: State changes immediately update local SRS metrics via the SpacedRepetitionService.
  • Microservice Integration: Custom Hugging Face endpoint (mms-tts-che) is asynchronously pinged for TTS, returning an MP3 byte stream cached locally to prevent redundant calls.
  • Cloud Synchronization: Encrypted SQLite database backups are pushed to Firebase Storage, linked to the user's Google Auth UID.

Engineering & Algorithmic Challenges

  • Spaced Repetition System (SRS): Built a custom interval-based algorithm mathematically calculating optimal review times, graduating words through complex state layers (newWord -> learning -> reviewing -> learned).
  • Orthographic Mapping: Implemented an AlphabetProvider that dynamically parses and maps dictionary entries between Cyrillic (Нохчийн) and Latin (Noxçiyn) representations in real-time.
  • Acoustic Model Integration: Engineered a bridge to a Massively Multilingual Speech (MMS) model hosted on Hugging Face, handling raw byte-stream conversions, asynchronous file I/O, and concurrent audio playback.

Future Research Focus

The next evolution of this project involves migrating the external Hugging Face TTS microservice to an on-device, lightweight local inference model for 100% offline capability. I also plan to develop a custom NLP lemmatizer to detect Chechen word roots and expand data pipelines for other Caucasian languages.
